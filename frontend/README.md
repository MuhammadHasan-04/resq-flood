# Frontend (to be built in Phase 1, weeks 4–5)

Planned: React + Leaflet map that calls the API.

- Flood mask for the selected date (`/flood/dates`)
- Roads coloured by state, from `/flood/{date}/summary` and the scored GeoJSON
- Route search (`/route?start_lon=..&start_lat=..&end_lon=..&end_lat=..&k=3`)
- Report form (`POST /reports`) and report list

A working static reference is `DADU_DATA/Dadu_Flood_Data_Atlas_offline.html`.
